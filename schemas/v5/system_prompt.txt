Extract all values directly from the financial statements tables (e.g. Consolidated Statements of Operations, Consolidated Statements of Cash Flows, Consolidated Balance Sheets, Segment Information). All monetary values must be reported in millions exactly as they appear in the tables. Do not round, convert, or summarize table values. For example, if a table shows 187,792 in a column labeled "(in millions)", return 187792, not 187.8. For segments, extract every reportable segment listed in the Segment Information table — do not skip any. For debt and lease repayments, use absolute values (positive numbers) even if the table shows them as negative.
